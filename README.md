# Isaac Yong (용이삭)

**X-ray physics · Scientific computing**

M.S. student in Physics at Sogang University.

I study X-ray scattering and diffraction, and build the software around the experiment:
thin-film reflectivity fitting ([ReflectoLearn](https://github.com/NaNIsaac/ReflectoLearn)),
phase retrieval for coherent imaging ([QoraPhase](https://github.com/NaNIsaac/QoraPhase)),
time-resolved data at PAL-XFEL ([QoraFlow](https://github.com/NaNIsaac/QoraFlow), [TraTT](https://github.com/NaNIsaac/TraTT)),
and calculators that still run on old beamline PCs ([xray.ooguy](https://xray.ooguy.com)).
